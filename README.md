# Talk: The Hitchhiker's Guide to Gradle Troubleshooting

Talk for [droidcon Berlin 2026](https://www.nextappcon.com/droidcon-new-speakers/marc-reichelt).

- Video recording: coming soon!

## Talk Description

Just want to focus on writing your app, but something with your build is amiss? Don't panic!

We'll do a deep-dive into how Gradle works under the hood: how do up-to-date-checks, build cache, remote build cache and configuration cache actually work? What's the Gradle daemon for, and why will it launch multiple daemons sometimes, eating up precious memory? Why will parallel builds work beautifully, until they don't? And in particular: what are some nice debugging skills we can use to find the root cause, and some special tips we can use to fix things?
And if that was not enough, we'll do it all live on stage!

Buckle up, and don't forget to bring your towels - it's going to be quite a ride!
